## 🧩 About

**Subnautica 2 Companion** is a curated list of Subnautica 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, depth gauge
- **Quality-of-Life Helpers** — inventory catalog, blueprint manager, overlay notes
- **Research Notes** — biome layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Exploration Helpers
- Depth Gauge — track current depth and pressure
- Resource Tracker — highlight nearby materials
- Biome Notes — record and review explored regions
- Swim Speed — adjust movement for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Blueprint Catalog — browse craftables, modules, upgrades
- Custom Skin Notes — organize vehicle cosmetics
- HUD Cleanup — improved visibility for deep dives

### 🏋️ Base Layout
- Habitat Notes — segment study on any layout
- Power Control — manually toggle base systems
- Storage Buffer Notes — chain complex builds in the editor
